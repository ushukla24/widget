Variables

A variable is a lot like a labeled box. You can put something inside the box, and you can swap out the contents whenever you want.

Meet the variable called score. Use the buttons or type a new number to change its value.

The variable score is one type of variable that holds a value called an integer.

Integers are positive and negative whole numbers (e.g. -3, 0, 42).

What are some other types of variables?

Some other common types of variables include:

  • Characters: a single letter or symbol, like 'A' or '?'.
  • Strings: words or sentences wrapped in quotes, like "hello world!" or "My score was 6.".
  • Booleans: true/false values that answer yes/no questions, like true or false.
